How to use it
  1. Press Notch. The glass lids open. Click a rotor, then type a letter or number, or drag its wheel. Press Notch again to close the lids.
  2. Set the start position by dragging the wheels, scrolling over them, or clicking a rotor and pressing the up and down arrow keys. Push the red slider to S to save it.
  3. Type your message on your keyboard or tap the keys. The screen shows the coded text.
  4. To decode, enter the same notches and start position, then type the coded text. Both sides must match exactly.
  5. Push the slider to R to rewind the rotors to the saved start before a new message. Backspace undoes the last symbol. Clear wipes the screen.
